    IMAS software¶

    The main open-source IMAS components. Each card links to the full documentation; the source code is on GitHub.

    Data model¶

    Data Dictionary

    Definition of all IDSs, with units, coordinates and identifiers. pip install imas-data-dictionary

    https://imas-data-dictionary.readthedocs.io/en/latest/
    GGD

    Library to build and use generalized grid descriptions. See Data on grids: the GGD.

    https://github.com/iterorganization/GGD

    Reading and writing IMAS data (Access Layer)¶

    IMAS-Python

    Python interface, also handles netCDF files and DD version conversion. pip install imas-python

    https://imas-python.readthedocs.io/en/stable/
    IMAS-Core

    Low-level library and storage backends (HDF5, MDSplus, UDA, …) used by all interfaces. pip install imas-core

    https://imas-core.readthedocs.io/en/latest/
    C++

    C++ interface (IMAS-Cpp).

    https://imas-cpp.readthedocs.io/en/stable/
    Fortran

    Fortran interface (IMAS-Fortran).

    https://imas-fortran.readthedocs.io/en/latest/
    MATLAB

    MATLAB interface (IMAS-MATLAB).

    https://imas-matlab.readthedocs.io/en/latest/
    Java

    Java interface (IMAS-Java).

    https://imas-java.readthedocs.io/en/latest/

    Exploring, checking and visualising data¶

    IDStools

    Command-line tools to list, print, plot, compare and manipulate IDS data. pip install imas-idstools

    https://imas-idstools.readthedocs.io/en/latest/
    IMAS-Validator

    Rule-based validation of IDS data. pip install imas-validator

    https://imas-validator.readthedocs.io/en/stable/
    IMAS-ParaView

    ParaView plugins to visualise IDS data, including GGD grids.

    https://imas-paraview.readthedocs.io/en/stable/

    Managing simulations¶

    SimDB

    Catalogue to publish, search and retrieve simulations. pip install imas-simdb

    https://simdb.readthedocs.io/en/latest/

    Building workflows¶

    iWrap

    Wraps Fortran, C++ and Python codes into actors for IMAS workflows.

    https://iwrap.readthedocs.io/en/stable/
    IMAS-MUSCLE3

    Generic actors and helpers to couple IMAS codes with MUSCLE3.

    https://imas-muscle3.readthedocs.io/en/latest/

    Something missing?

    Software listed here is open source and installable without access to a specific site. To propose another component, open an issue.

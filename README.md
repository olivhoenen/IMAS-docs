# IMAS documentation hub

Source of the open-access IMAS documentation hub:
**https://olivhoenen.github.io/IMAS-docs/**

The hub explains what IMAS (the Integrated Modelling & Analysis Suite) is and how to get started,
organised around **user stories**: background, how IMAS addresses the problem, a short working
example, and links to the full documentation of each IMAS software component. It points to
that documentation and does not replace it.

Hands-on notebooks live in [IMAS-tutorial](https://github.com/iterorganization/IMAS-tutorial)
and are rendered on the site under *Tutorials*.

## Contributing

- **Tell us your story**: [open a user story](https://github.com/olivhoenen/IMAS-docs/issues/new?template=user_story.yml).
- **Fix or write a page**: see [CONTRIBUTING.md](CONTRIBUTING.md). Pages are Markdown files in
  `docs/`, and every pull request gets a preview of the rendered site.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
